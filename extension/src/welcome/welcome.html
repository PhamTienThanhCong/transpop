A few more tricks

Pin TransPop to the toolbar

Click the puzzle icon in Chrome's toolbar, then the pin next to TransPop.

Keyboard shortcut

Select text, then press the shortcut to translate it.

Copy Translate “…”

Right-click to translate

Select text, right-click and choose Translate “…”.

Translate text in images

Right-click an image and choose “Translate text in image”, or click “Translate screen area” in the TransPop popup.

You can change all of this later in Settings.
