# TransPop — Architecture & Team Contract

> **TransPop** — *Select to translate.* An open-source (MIT) Chrome extension (Manifest V3) that
> translates any selected word or phrase into the user's language, with a DDict-style bubble,
> a full translator popup, dictionary/definitions/examples, text-to-speech, history and favorites.

This document is the **single source of truth** shared by every contributor (human or agent).
If you need something that is not here, follow the closest existing convention and note it in
your final report — do **not** silently invent a different contract.

---

## 1. Principles

1. **No build step.** Plain modern JavaScript (ES2022), HTML, CSS. The `extension/` folder is
   loaded unpacked and zipped as-is. No frameworks, no bundlers, no npm runtime dependencies.
2. **MV3 rules.** No remote code, no `eval`, no inline `<script>` / inline event handlers
   (`onclick=` etc.) — extension CSP forbids them. Only `<script src>` / `<script type="module" src>`.
3. **Security.** Never put translated/remote/user text into `innerHTML`. Use `textContent`
   or build DOM nodes. The only exception: Google example sentences contain `<b>` tags — parse
   them with a tiny whitelist renderer (split on `<b>`/`</b>`, create `<strong>` nodes), never innerHTML.
4. **Privacy.** Text is sent only to the selected translation provider, only when a translation is
   requested. No analytics, no tracking, no remote fonts, no third-party scripts.
5. **Minimal permissions.** Do not add permissions/host permissions without the manager's approval.
6. **Accessible & professional UI.** Keyboard reachable, `aria-label` on icon buttons, visible focus
   rings, light + dark theme, RTL-aware text output (`dir="auto"` / `isRtl()`).
7. **Localized UI.** Every user-visible string goes through `chrome.i18n` (see §8). English + Vietnamese.

## 3. Manifest (summary — see `extension/manifest.json`)

- `permissions`: `storage`, `contextMenus`, `offscreen`, `tts`
- `host_permissions`: `https://translate.googleapis.com/*`, `https://translate.google.com/*`,
  `https://edge.microsoft.com/*`, `https://api-edge.cognitive.microsofttranslator.com/*`, `https://www.bing.com/*`
- `background.service_worker`: `src/background/service-worker.js` (`"type": "module"`)
- `content_scripts`: `<all_urls>`, `all_frames: true`, `match_about_blank: true`, `run_at: document_idle`
- `action.default_popup`: `src/popup/popup.html`
- `options_ui`: `src/options/options.html`, `open_in_tab: true`
- `commands`: `_execute_action` (Alt+Shift+T), `translate-selection` (Alt+Shift+S), `toggle-enabled` (no default)
- `minimum_chrome_version`: `116`

## 4. Settings (`chrome.storage.sync`, key `settings`)

Always read through `getSettings()` (merges defaults + validates). Content scripts can't import
modules, so they ask the background: `{type: 'get-settings'}` → `{ok, settings}` and listen to
`chrome.storage.onChanged` (area `sync`, key `settings`) to re-fetch.

| key | type / values | default | meaning |
|---|---|---|---|
| `enabled` | bool | `true` | master switch for in-page translation (popup always works) |
| `targetLang` | lang code | UI language (e.g. `vi`), fallback `en` | translate INTO this |
| `secondaryLang` | lang code | `en` (or `vi` if targetLang is `en`) | used when the detected source == targetLang |
| `triggerMode` | `'icon'` \| `'auto'` \| `'hotkey'` | `'icon'` | **icon**: small TransPop button appears near the selection, click → bubble (DDict style). **auto**: bubble appears right after selecting. **hotkey**: nothing appears until the user holds `modifierKey` while selecting, or taps `modifierKey` alone while text is selected |
| `modifierKey` | `'Shift'` \| `'Alt'` \| `'Control'` \| `'Meta'` | `'Shift'` | key for hotkey mode (also works as an instant trigger in icon mode) |
| `doubleClickOnly` | bool | `false` | auto mode only: trigger on double-click (single words) only |
| `provider` | `'google'` \| `'microsoft'` | `'google'` | primary provider; the other one is automatic fallback |
| `showPhonetic` | bool | `true` | show source transliteration/phonetic in bubble |
| `showDictionary` | bool | `true` | parts-of-speech + alternative translations |
| `showDefinitions` | bool | `true` | monolingual definitions (when available) |
| `showExamples` | bool | `true` | example sentences |
| `autoSpeak` | bool | `false` | speak the source word when the bubble opens (single words / ≤ 3 words only) |
| `speechRate` | number 0.5–1.5 | `1` | TTS rate |
| `theme` | `'auto'` \| `'light'` \| `'dark'` | `'auto'` | applies to bubble, popup, options |
| `fontSize` | int 12–20 | `14` | bubble base font size (px) |
| `disableInInputs` | bool | `true` | ignore selections inside input/textarea/contenteditable |
| `disabledSites` | string[] hostnames | `[]` | no in-page translation on these hostnames (exact host or subdomain match) |
| `saveHistory` | bool | `true` | record translations in history |
| `closeOnClickOutside` | bool | `true` | close bubble when clicking elsewhere |

Enums and defaults live in `src/shared/constants.js` (`DEFAULT_SETTINGS`, `TRIGGER_MODES`, …).

### Local data (`chrome.storage.local`)

- `history`: `Entry[]`, newest first, max `LIMITS.HISTORY_MAX` (500), de-duplicated by `key`.
- `favorites`: `Entry[]`, newest first, max `LIMITS.FAVORITES_MAX`.
- `popupState`: `{ text, from, to }` last popup input (restore on reopen).

```ts
type Entry = {
  id: string;          // crypto.randomUUID()
  key: string;         // makeEntryKey(text, to) = `${to}|${text.trim().toLowerCase()}`
  text: string;        // source text
  translation: string; // main translation
  from: string;        // detected/actual source language code
  to: string;          // target language code
  phonetic?: string;   // source transliteration if any
  ts: number;          // Date.now()
}
```

Helpers (in `storage.js`): `getSettings, saveSettings(patch), resetSettings, onSettingsChanged(cb)`,
`getHistory, addHistoryEntry(entry), removeHistoryEntry(id), clearHistory, onHistoryChanged(cb)`,
`getFavorites, isFavorite(text,to), toggleFavorite(entry) → bool, removeFavorite(id), clearFavorites, onFavoritesChanged(cb)`,
`exportData() → object, importData(object)`, `makeEntryKey(text,to)`, `entryFromResult(result)`,
`isSiteDisabled(settings, hostname)`.

## 5. Messaging contract

All messages use `chrome.runtime.sendMessage` / `chrome.tabs.sendMessage`. **Every response is an envelope:**

```js
{ ok: true, ...data }                        // success
{ ok: false, error: { code, message } }      // failure; code ∈ ERROR_CODES
```

Extension pages use `send(type, payload)` from `src/shared/messaging.js` (returns data or throws an
`Error` with `.code`). The content script uses its own tiny equivalent (it can't import modules).
Handlers that answer asynchronously must `return true` from the `onMessage` listener.

### Requests handled by the background (service worker)

| `type` | payload | response data |
|---|---|---|
| `translate` | `{ text, from?='auto', to?, source?: 'bubble'\|'popup'\|'context-menu'\|'welcome', record?: boolean = true }` | `{ result: TranslationResult }` |
| `speak` | `{ text, lang }` | `{}` — plays Google TTS via offscreen doc; falls back to `chrome.tts` |
| `stop-speak` | `{}` | `{}` |
| `get-settings` | `{}` | `{ settings }` |
| `open-options` | `{ section? }` | `{}` — opens options page (optionally `#section`) |
| `toggle-favorite` | `{ result: TranslationResult }` | `{ favorited: boolean }` |
| `check-favorite` | `{ text, to }` | `{ favorited: boolean }` |
| `disable-site` | `{ hostname }` | `{ settings }` |

**`translate` semantics:**
- `text` is trimmed; empty → `EMPTY`; longer than `LIMITS.MAX_TEXT_LENGTH` (5000) → `TOO_LONG`.
- If `to` is **omitted**: use `settings.targetLang`; if the detected source equals `targetLang`,
  re-translate into `settings.secondaryLang` ("smart swap"). If `to` is **given**, no swap.
- Results are cached in memory (LRU, `LIMITS.CACHE_MAX`) keyed by `provider|from|to|text`.
- If `settings.saveHistory` and `record !== false` and `source !== 'welcome'`, an `Entry` is added to history.
  (The popup sends `record: false` while the user is typing and `record: true` once input settles ≥ 1.5 s,
  on Enter, or on blur — the second call is served from cache.)
- Provider failure → automatic fallback to the other provider before returning an error.

### Requests handled by the content script (sent by background or popup via `chrome.tabs.sendMessage`)

| `type` | payload | response data |
|---|---|---|
| `show-translation` | `{ text? }` | `{ shown: boolean }` — show the bubble for `text` (context menu) or for the current selection (keyboard command, sent to all frames: only a frame that actually has a selection shows it and answers `shown: true`; others answer `shown: false` only if they are the top frame, otherwise don't respond); anchor = selection rect, else top-center of viewport. **Explicit requests (context menu / command) work even when `enabled` is false or the site is disabled** — those switches only gate passive triggers. |
| `get-selection` | `{}` | `{ text, hostname }` — current selection text + `location.hostname` (top frame, `frameId: 0`); the popup uses it to prefill and to show the per-site toggle (so we don't need the `tabs` permission) |
| `ping` | `{}` | `{}` |

### Popup URL parameters

`src/popup/popup.html?text=<urlencoded>` prefills + translates (used by the background's context-menu fallback
when no content script is reachable, opened via `chrome.windows.create({type: 'popup'})` with `&view=window`).
`?view=tab` = full-page translator layout (opened by the popup's "expand" button). Default (no param) = toolbar popup.

### Offscreen document (internal to background agent)

`offscreen-play { url | urls[] , rate }`, `offscreen-stop {}` — target: offscreen only (include `target: 'offscreen'` in the message and have other listeners ignore it).

### `TranslationResult`

```ts
type TranslationResult = {
  text: string;                 // original (trimmed) text
  translation: string;          // full translated text (sentences joined)
  from: string;                 // detected (or given) source language, Google-style code
  to: string;                   // target language code actually used (after smart swap)
  provider: 'google' | 'microsoft';
  confidence?: number;          // 0..1 language-detection confidence
  phonetic?: string;            // transliteration of the SOURCE text, e.g. "ˈäbvēəs" / "nǐ hǎo"
  translit?: string;            // transliteration of the TRANSLATION (e.g. for ja/zh/ru targets)
  alternatives?: string[];      // alternative translations of the whole text (short texts)
  dictionary?: Array<{          // bilingual dictionary — single words / short phrases
    pos: string;                // part of speech as returned by the provider, e.g. "noun"
    terms: string[];            // translations for that pos, best first
    entries?: Array<{ word: string; reverse: string[]; score?: number }>;
  }>;
  definitions?: Array<{         // monolingual definitions in the SOURCE language
    pos: string;
    items: Array<{ definition: string; example?: string }>;
  }>;
  examples?: string[];          // example sentences in the source language (may contain <b>…</b>)
  synonyms?: Array<{ pos: string; terms: string[] }>;
  cached?: boolean;
}
```

Fields other than `text, translation, from, to, provider` are optional — UIs must render gracefully when absent.

### `ERROR_CODES`

`EMPTY`, `TOO_LONG`, `NETWORK`, `RATE_LIMITED`, `PROVIDER_ERROR`, `UNSUPPORTED_LANG`, `UNKNOWN`.
UIs show a friendly localized message per code (`common_error_<code>` keys in `i18n/common.json`) plus a Retry button.

## 6. Translation providers (background agent)

- **Google (primary, free web endpoint):**
  `POST https://translate.googleapis.com/translate_a/single?client=gtx&sl={from}&tl={to}&hl={uiLang}&dj=1&dt=t&dt=bd&dt=rm&dt=md&dt=ex&dt=ss&dt=at&ie=UTF-8&oe=UTF-8`
  with body `q=<urlencoded text>` (`Content-Type: application/x-www-form-urlencoded;charset=UTF-8`).
  `dj=1` returns a JSON object (`sentences`, `dict`, `src`, `confidence`, `definitions`, `examples`, `synsets`, `alternative_translations` …).
  Only request `bd/md/ex/ss/at` for short inputs (≤ 60 chars, ≤ 5 words) to save bandwidth.
- **Microsoft (fallback, free Edge endpoint):** token from `GET https://edge.microsoft.com/translate/auth`
  (JWT, cache ~8 min), then `POST https://api-edge.cognitive.microsofttranslator.com/translate?api-version=3.0&to={to}[&from={from}]`
  with `Authorization: Bearer <token>` and body `[{"Text": "..."}]`. Map language codes (`zh-CN↔zh-Hans`,
  `zh-TW↔zh-Hant`, `iw↔he`, `tl↔fil`, `jw↔jv`, `no↔nb`, `mni-Mtei↔mni`…).
  *Status (2026-11): the Edge auth endpoint returns 404*, so the provider falls back to a second transport:
  the Bing web translator (`GET https://www.bing.com/translator` → session IG/IID/key/token, then
  `POST /ttranslatev3` and `/tlookupv3`, same JSON schema as Translator v3; texts ≤ 1000 chars).
  Requires host permission `https://www.bing.com/*`.
- All provider strings are Unicode-NFC normalized (Google sometimes returns decomposed dictionary terms).
- `speak` also accepts an optional `rate`; callers should pass a concrete language (`result.from`), not `auto`.
- **TTS:** `https://translate.google.com/translate_tts?ie=UTF-8&client=tw-ob&tl={lang}&q={text}` (chunk ≤ 200 chars at
  sentence/space boundaries), played in an **offscreen document** (`reasons: ['AUDIO_PLAYBACK']`). Fallback: `chrome.tts.speak`.
- `translator.js` and `providers/*.js` must be **pure** (only `fetch`, no `chrome.*`) so they run in Node 24 for tests
  and for the dev server. Response parsing lives in exported pure functions (`parseGoogleResponse(json, text)` etc.).

## 8. Internationalization

- Source of truth: `i18n/<area>.json` fragments. Format:
  ```json
  { "popup_translate": { "en": "Translate", "vi": "Dịch", "description": "Primary button" } }
  ```
  Positional substitutions use `$1`…`$9` in the text (the build converts them to Chrome placeholders).
- Build: `node scripts/build-locales.mjs` merges all fragments → `extension/_locales/{en,vi}/messages.json`
  and fails on duplicate keys or missing translations. Run it after editing fragments.
- Key prefixes per area: `common_` (manager), `meta`-level keys like `extName` (manager), `bg_` (background),
  `bubble_` (content), `popup_` (popup), `options_` / `welcome_` (options).
- In code: `t('popup_translate')` (`src/shared/i18n.js`) or `chrome.i18n.getMessage(...)` in the content script.
  In HTML: `data-i18n="key"`, `data-i18n-placeholder`, `data-i18n-title`, `data-i18n-aria-label`, then `localizeDocument()`.
- Language **names** are NOT in messages: use `getLanguageName(code)` (Intl.DisplayNames in the UI locale).

## 9. Quality bar

- `node --check` passes for every JS file; `node scripts/build-locales.mjs` passes.
- No console errors on load; no unhandled promise rejections (`chrome.runtime.lastError` checked where relevant;
  "Receiving end does not exist" handled gracefully).
- Works on: ordinary sites, sites with strict CSP, iframes, dark sites, RTL pages, pages with huge z-index overlays.
- Bubble never breaks the host page (Shadow DOM, `all: initial`, max z-index, no global listeners that `preventDefault`).
- UI tested at 100% zoom, popup width 400px, options page responsive ≥ 360px.
